# JSX styles

Run `cargo run -p jsx-styles` to open the native styling gallery.

The gallery shows circular and linear gradients, box shadows, borders,
`border-box` and `content-box`, padding and margin shorthands, styled text,
flex and grid layout, and buttons with shared and inline styles.

`cargo run -p universal-styles` shows the same style system through Rust widget
builders without JSX.
